{#- Self-hosting in a terminal: the README's quick start, with the output docker compose actually prints and the shape /health actually answers. -#}
~/argusmetrics
$ git clone https://github.com/Benbo-se/ArgusmetricsSH
Cloning into 'ArgusmetricsSH'... done.
$ cd ArgusmetricsSH/docker
$ cp .env.example .env
# then set SECRET_KEY in .env, the one required value
$ docker compose up -d postgres backend
✔ Container argusmetrics-postgres Healthy
✔ Container argusmetrics-backend Started
$ curl -s localhost:8020/health
{"status": "healthy", "database": "connected", "jobs": {…}}
