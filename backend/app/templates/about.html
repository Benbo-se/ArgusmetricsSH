About Argusmetrics

Privacy-first web analytics that respects your users

Our Mission

We believe that web analytics doesn't have to come at the cost of user privacy. Argusmetrics provides powerful insights without tracking users across the web, using cookies, or collecting personal data.

🔒

Privacy First

No cookies, no cross-site tracking, no personal data collection. 100% GDPR compliant by default.

Transparent

Why We Built This

We were tired of the complexity and privacy concerns of traditional analytics tools. Google Analytics is overkill for most websites, and its tracking practices raise serious privacy questions.

Existing privacy-focused alternatives were great, but often expensive or lacked key features. We wanted to build something that was:

  • Truly privacy-respecting (no cookies, no tracking)
  • Affordable for everyone (starting at 79kr/month)
  • Simple to use (5-minute setup)
  • Powerful enough for serious businesses
  • Built on modern, maintainable technology

Argusmetrics is the result - a privacy-first analytics platform that doesn't compromise on features or usability.

Built with Modern Technology

We use a proven, scalable tech stack:

Backend: Python + FastAPI
Database: PostgreSQL
Frontend: HTMX + Alpine.js + Tailwind
Tracking: Vanilla JavaScript (< 4KB)
