Track 404 Errors

Automatically track which pages return 404 errors to find and fix broken links.

Benefits

  • Find broken internal links before they hurt user experience
  • Discover broken external links pointing to your site
  • Track which pages users expected to find
  • See referrers that lead to 404 errors

Setup Instructions

Add this code to your 404 error page template (usually 404.html or 404.php): 

<script>
  if (window.argus) {
    argus.trackEvent('404 Error', {
      path: window.location.pathname,
      referrer: document.referrer
    });
  }
</script>

Platform-Specific Examples

WordPress

Add to your theme's 404.php file:

<?php if ( ! defined( 'ABSPATH' ) ) exit; ?>
<?php get_header(); ?>

<!-- Your 404 page content -->

<script>
  if (window.argus) {
    argus.trackEvent('404 Error', {
      path: window.location.pathname,
      referrer: document.referrer
    });
  }
</script>

<?php get_footer(); ?>
Next.js

Add to your pages/404.js file:

import { useEffect } from 'react';

export default function Custom404() {
  useEffect(() => {
    if (window.argus) {
      window.argus.trackEvent('404 Error', {
        path: window.location.pathname,
        referrer: document.referrer
      });
    }
  }, []);

  return <h1>404 - Page Not Found</h1>;
}
Static HTML / Other

Add to your 404.html file before closing </body> tag:

<!-- Your 404 page content -->

<script>
  if (window.argus) {
    argus.trackEvent('404 Error', {
      path: window.location.pathname,
      referrer: document.referrer
    });
  }
</script>
</body>

Important Notes:

  • Make sure the tracking script is already loaded on your 404 page
  • This requires manual setup - 404 errors are not tracked automatically
  • Check your 404 errors in the dashboard Analytics section
