How to track goals

To track goal conversions, add this JavaScript code to your website where the conversion happens (e.g., on button click, form submission): 

<button onclick="argus.trackEvent('your_event_name')">
  Sign Up
</button>

Example Usage:

argus.trackEvent('newsletter_signup') - Track newsletter signups

argus.trackEvent('purchase_completed') - Track purchases

argus.trackEvent('download_clicked') - Track downloads

Make sure the tracking script is installed on your website first. The event name must match the "Event Name" field in your goal configuration.
