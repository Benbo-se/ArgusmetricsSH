About Argusmetrics

Privacy-first web analytics that respects your users

Our Mission

We believe that web analytics doesn't have to come at the cost of user privacy. Argusmetrics is free, open source (AGPL-3.0) and self-hosted, providing powerful insights without tracking users across the web, using cookies, or collecting personal data. You run it yourself, so your data stays on your own infrastructure.

🔒

Privacy First

No cookies, no cross-site tracking, no personal data collection. 100% GDPR compliant by default.

⚡

Simple & Fast

Lightweight < 4KB tracking script. Clean interface. Get insights in seconds, not hours.

🎯

Open & Transparent

Open source under AGPL-3.0, no data selling, no surprises. You self-host and own your data, always.

Why We Built This

We were tired of the complexity and privacy concerns of traditional analytics tools. Google Analytics is overkill for most websites, and its tracking practices raise serious privacy questions.

Existing privacy-focused alternatives were great, but often closed-source or locked behind a subscription. We wanted to build something that was:

  • Truly privacy-respecting (no cookies, no tracking)
  • Free and open source (AGPL-3.0)
  • Self-hosted, so your data stays on your own infrastructure
  • Simple to run (clone the repo and start with Docker Compose)
  • Built on modern, maintainable technology

Argusmetrics is the result - a free, open-source, self-hosted privacy-first analytics project that doesn't compromise on features or usability.

Built with Modern Technology

We use a proven, scalable tech stack:

Backend: Python + FastAPI
Database: PostgreSQL
Frontend: HTMX + Alpine.js + Tailwind
Tracking: Vanilla JavaScript (< 4KB)
