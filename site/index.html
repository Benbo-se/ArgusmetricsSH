bash — self-host quickstart 
$ git clone https://github.com/Benbo-se/ArgusmetricsSH
$ cd ArgusmetricsSH/docker
$ docker compose up -d

Needs only Docker. Your dashboard is live on localhost:8020 — add the tracking snippet to any site and you're done.
