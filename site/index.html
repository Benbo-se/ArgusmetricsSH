    01

    No IP address is ever stored

    Not truncated, not encrypted, not anywhere. There is no column for it, and none for the user agent either. Country comes from a database on the server itself, so your visitors' addresses are never sent to a third party.

    02

    The visitor hash changes daily

    The address is truncated first, IPv4 to a /24 and IPv6 to a /48, then hashed with the browser, your domain and a salt that changes every day. The same visitor tomorrow is a different hash, and everyone on the same network is the same one.

    03

    Nothing is written to the visitor's browser

    No cookie, no localStorage, no fingerprint. The script sends an event and forgets. That is why no consent banner is needed, rather than a banner being technically avoidable.

    04

    The database enforces the separation

    Every table holding your data has row-level security policies, and the application connects as a role those policies apply to. A bug in the code cannot show your data to someone else, because the database refuses independently.

    05

    Credentials are never stored usably

    Passwords, session tokens and API tokens are all hashed. A copy of the database grants access to nothing. Sessions are Secure, HttpOnly and SameSite, and the dashboard loads no third-party scripts at all.

    06

    Do Not Track is honoured

    A visitor whose browser sends Do Not Track is not recorded at all. Not anonymised, not counted separately. Nothing is written.
